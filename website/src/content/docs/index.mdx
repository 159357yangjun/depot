Multi-cloud Publisher 的目标不是让你先学习“图床”，而是尽快得到一条别人能访问的图片链接。

<Steps>
1. **连接一个云端**：新用户建议 Cloudflare R2；开发文档可以选择 GitHub / Gitee。
2. **添加一个 Recipe**：推荐“博客 · WebP 均衡”，它会自动缩放、转 WebP、重命名并发布。
3. **拖入图片**：桌面端选择默认方案后直接发布，完成后在“资源”页复制 URL / Markdown。
</Steps>

> Token 和 Secret 只在桌面端录入并写入系统凭据库。教程页面不会要求你粘贴密钥。
